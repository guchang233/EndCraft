# EndCraft v1.0.0

日期：2026-10-07。此版本发布当前联动原型，实际玩法模块身份保留为 `endcraft.gameplay15`，共享内存协议版本为 12。

## 已实现并有本机验证

- 真实《终末地》中显示 MC 角色、装备、物品栏，以及放置的 MC 方块。
- MC 网格通过 HGRP 原生场景管线绘制，使用宿主场景深度，原生 UI 绘制在世界网格之后。
- 桥接接管移动及视角，俯仰范围为 ±90°；第三人称相机执行宿主射线避障。
- MC 客户端与内置服务器使用同一平滑地形碰撞算法，保留普通 MC 方块碰撞。
- 提供热加载、诊断、构建和按自有文件哈希保护的安装/卸载工具。

## 已知问题及尚未完成

- 用户报告鞘翅无法正常使用；装备与烟花存在不代表滑翔和推进已经完成。
- MC HUD/库存画面固定为 640×360，放大到宿主窗口后清晰度不足。
- 尚未将 MC 攻击转交给《终末地》的正常战斗流程；不能据此声称剑、弓或 TNT 可以伤害宿主敌人。
- 连续走路卡住的问题仍需复验。当前高度场不能完整表示墙壁、洞穴、桥洞等复杂碰撞。
- NPC 对新增方块的碰撞/寻路、输入隔离、场景切换及失联恢复尚未完整验收。
- 只在本机的一组版本上验证，尚无其他设备、显卡或后续游戏版本兼容保证。

## 版本和产物

验证环境：Windows x64、Unity 2021.3.34f5 IL2CPP/Vulkan、Minecraft Java 26.3、Fabric Loader 0.19.5、Fabric API 0.161.0+26.3、JDK 25。外部源码提交及许可证见 `THIRD-PARTY-NOTICES.md`。

- `EndCraft-gameplay15-1.0.0-win-x64.zip`：玩法模块 DLL、1.0 发行清单及许可证。内部模块身份与第 15 版兼容。
- `endcraft-guest-1.0.0.jar`：独立 MC 端 Fabric 模组。
- `EndCraft-1.0.0-source.zip`：项目对应源码及两个固定提交的完整上游源码，可重建 Host 与加载器。
- `SHA256SUMS.txt`：本次发行附件的 SHA256 校验。

模块 ZIP 和 MC JAR 需要配套 Host、独立 MC 开发实例与安装配置，不能仅把 JAR 放入终末地目录后启动。当前发行面向源码构建和试验；入口、构建及安装步骤见 README。源码中部分实机诊断路径仍沿用开发机路径，移植到其他目录时需要调整。
