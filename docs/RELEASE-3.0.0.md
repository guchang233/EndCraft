# EndCraft v3.0.0

日期：2026-10-08。实验性联动原型，作为预发行发布。宿主模块 `endcraft.gameplay33`，共享内存协议 12；保留 1.0、2.0 标签与附件。

## 主要变化

- 修复玻璃及染色玻璃透明显示；将透明方块和流体与实体网格拆分，保留原生场景深度遮挡。
- 修复 MC 水颜色、透明混合与纹理动画；接收图集区域更新并按帧合并应用。流体视觉网格不再生成实体碰撞墙。
- 修复高速上坡时遗漏坡面的问题，增加脚下／邻格采样；地形仍为高度场。
- 修复 MC 输入回调与保存退出之间的锁等待死锁。
- MC 命中后调用原生受击组件，实测 12 次伤害转交及 6 次受击状态变化。
- 热更新和启动保留已验证存档锚点，从实际宿主位置重新同步，避免建筑因重新初始化漂移。
- 重写 README，增加安装／升级、操作、排错及架构教程；启动脚本支持显式 JDK 与 ENDCRAFT_JAVA_HOME，不再依赖开发机目录名判断自己的 MC 进程。

保留 2.0 的原生传送恢复、MC 战斗伤害、创造免伤、鞘翅／烟花、实体显示及普通体型载具乘客功能。

## 验证

用户放置普通玻璃、染色玻璃与水后确认“玻璃和水都正常”。原生渲染错误为空，透明网格与图集动画计数持续更新。MC 30 项测试通过，原生分层／纹理区域、输入、模块生命周期及既有基础检查通过；安装文件保护另有 7 项测试。

详细证据与适用范围见 [第 31 版](VALIDATION-gameplay31.md)、[第 33 版](VALIDATION-gameplay33.md)；自动测试和调用计数不代替所有场景的实机验收。

## 下载与使用

| 附件 | 内容 |
|---|---|
| `EndCraft-gameplay33-3.0.0-win-x64.zip` | 宿主模块、清单、教程与许可证 |
| `endcraft-guest-3.0.0.jar` | 配套 Fabric MC 模组 |
| `EndCraft-3.0.0-source.zip` | 对应项目源码与固定提交的两份上游源码 |
| `SHA256SUMS.txt` | 以上附件的校验值 |

**仍需配套 Host、加载器和独立 MC 源码实例，不是一键安装包。** 完整流程见 [安装与升级教程](INSTALL.md)，按键、指令与恢复见 [操作教程](USER-GUIDE.md)。

2.0 升级应保留原安装目录、存档和旧锚点，停止旧玩法模块后切到 gameplay33；只启用一个玩法模块。默认独占开关开启，分号关闭后 MC 仍可能响应同一按键。
