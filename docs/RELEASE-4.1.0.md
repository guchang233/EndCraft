# EndCraft v4.1.0

4.1 为 NeoForge 1.21.1 客户端加入**局域网联机**，并修复首轮联机实测中的显示与按键问题。Fabric 26.3 客户端与 4.0 相同。

## 新增

| 内容 | 说明 |
|---|---|
| 开放局域网 | 主机在 MC 聊天输入 `/endcraft lan [offline] [cheats] [端口]`，或在 `skycraft.properties` 设置 `lan=true`；`offline` 不验证正版账号，`cheats` 允许访客使用指令 |
| 普通访客 | 只运行 NeoForge 客户端即可加入；出生在主机身边，主机服务器同步附近的终末地地形碰撞和三角面，访客端显示为按材质着色的地面 |
| 自带终末地的访客 | `/endcraft join [地址]` 加入（不填地址时自动搜索局域网世界），`/endcraft leave` 返回；`tools/show-anchor.py` 与 `configure-gameplay-startup.py --anchor` 统一两边的世界锚点；快速传送通知服务器 |
| 地形线框 | 引号键 `'` 在终末地中显示终末地发送给 MC 的地形三角面（绿：可行走地面，蓝：物体上的可行走面，橙：墙面与陡坡，黄：隐形台阶坡道） |
| 碰撞箱 | F3+B 的碰撞箱可在终末地中显示；终末地 NPC 的替身以品红色框显示 |
| F1 / F3 | 新宿主模块 `gameplay34` 把 F1、F3 转发给 MC（升级方法见 [NeoForge 说明](NEOFORGE.md)） |
| 一键重启 | `restart-neoforge-mc.cmd`：终末地仍在运行而 MC 崩溃时，重新启动桥接客户端并连回终末地 |

## 修复

| 现象 | 原因与修复 |
|---|---|
| MC 角色的手臂、身体、披风互相穿插 | 皮肤按半透明导出，终末地不写深度；皮肤改为镂空导出 |
| 角色头顶白条 | 名牌文字的背景和颜色在终末地中无法还原；不再导出文字 |
| 原生测试在 CI 上偶发卡死 | 模拟宿主输出写满管道后无法退出；改为写入临时文件，超时时报告模拟宿主状态 |

## 已知限制

- 两台电脑各自运行终末地的联机尚未实机验证；同一台电脑上的普通访客已验证。
- 普通访客只能看到主机终末地角色附近的地形；终末地 NPC 在普通访客端不可见。
- `gameplay34` 的 F1/F3 转发尚未实机验证。
- 4.0 的已知限制仍然适用，见 [4.0 更新说明](RELEASE-4.0.0.md)。

联机步骤见 [局域网联机说明](MULTIPLAYER.md)。
