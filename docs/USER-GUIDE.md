# 游戏内操作教程

开始前完成 [安装](INSTALL.md)，进入终末地可移动场景并等待 MC 物品栏出现。以下操作针对项目的独立 MC 世界。

## 第一次检查

1. 按 F5 切换第一人称、第三人称后视和前视，确认角色位置与场景一致。
2. 用 WASD、空格走动和跳跃，先在空旷地面测试。
3. 按 E 打开库存，选少量方块到快捷栏；关闭库存后用右键放置、左键破坏。
4. 放普通玻璃、染色玻璃和一桶水，观察透明、颜色、流动以及场景前后遮挡。

MC 方块保存在项目世界中。放置距离、物品消耗和破坏时间依赖 MC 当前模式及物品；并非所有原生场景物件都能按 MC 方块挖除。

## 按键

| 按键 | 用途 |
|---|---|
| WASD | 移动 |
| 空格 | 跳跃；空中展开鞘翅；创造模式双击切换飞行 |
| Shift | 潜行、创造飞行下降、下船／下矿车 |
| Ctrl | MC 默认冲刺绑定 |
| 1–9、滚轮 | 快捷栏选择 |
| 左键 | 攻击或破坏 |
| 右键 | 使用物品、放置、与载具交互 |
| E | 库存 |
| F5 | 切视角 |
| T、`/` | MC 聊天与指令 |
| Ctrl+Alt+R | 位置恢复 |
| `;` | 当前实验性输入独占开关 |

分号开启时优先把原生绑定分发屏蔽，让 MC 接收输入；关闭时恢复原生绑定，**MC 仍可能接收同一输入**。3.0 未实现“按键使用对象二选一”的完整互斥切换。使用原生地图前先松开移动与鼠标，收起 MC 库存，再关闭独占；仍有冲突时不要连续触发两边操作。

## 游戏模式与指令

按 `/` 或 T，输入后按 Enter：

```text
/gamemode creative
/gamemode survival
/gamemode adventure
/gamemode spectator
```

创造与旁观模式把 MC 的免伤状态同步到当前宿主角色；切回生存或停用桥接会撤销桥接自己的保护。免伤不会补满切换前已经损失的宿主血量。

指令权限只属于项目的集成镜像世界，其他 MC 实例和远程服务器不受影响。ASCII 指令可用，中文输入法的组合输入尚未接入。其他 MC 指令按版本、权限和当前模式执行，不保证每个改变世界的指令都有对应原生效果。

## 玻璃与水

普通玻璃的透明像素、染色玻璃的半透明效果和 MC 水动画已实机确认。方块和流体交给宿主 HGRP 绘制，仍使用原生场景深度。

水桶放出的水按 MC 规则流动；建造水池时先放底板和围墙，避免水铺满测试区。MC 水不创建实体碰撞墙。终末地已有的水面仍属于原游戏，尚未变成 MC 流体，也不能据此保证船在原生水域具有完整 MC 浮力。

复杂交叠透明面、水下视觉、波浪反射和折射未全面适配。

## 鞘翅与烟花

1. 切到创造模式，准备鞘翅和烟花。
2. 将鞘翅穿在胸甲栏，选择烟花。
3. 从有足够高度的位置跳出，在空中再按空格展开鞘翅。
4. 右键使用烟花推进，鼠标控制方向。

鞘翅进入镜像世界时会修复并设为不损耗。飞行遵循 MC 的展翼与推进机制；贴地起飞、复杂坡面和连续起降仍可能受当前碰撞采样影响。先在开阔区域测试。

## 战斗与 TNT

剑、弓及 TNT 由 MC 判断命中、冷却、暴击、附魔与最终伤害，宿主再接收这些结果。当前伤害比例为：

```text
宿主伤害 = MC 最终伤害 / 20 × 目标最大生命
```

例如 MC 最终伤害为 7 时，对应目标最大生命的 35%；并不代表每次点击都造成这个伤害，MC 攻击冷却和具体武器仍影响最终数值。

成功提交伤害后调用宿主受击组件。普通命中请求轻受击，暴击或爆炸请求较强受击；霸体、动画状态和敌人类型仍由原游戏决定。并非每击都必须出现同样的动作。

TNT 可以破坏玩家放置的 MC 方块，并对范围内宿主敌人代理计算伤害。已实测敌人死亡与原生任务击杀计数。**TNT 炸原生可破坏岩石仍是待验证接口**：需要一次真实原生炸弹命中样本，且岩石必须属于游戏原本支持炸开的对象。3.0 不把该功能作为已完成宣传，也不支持随意挖掉原生地表。

跨会话奖励与重新登录后的战斗状态持久性尚未验证。

## 船、矿车与乘客

在空旷位置右键放船，右键乘坐，Shift 下船。矿车按 MC 轨道和实体规则使用。下车流程检查宿主地面与已放置方块，避免落点埋在地形中；多层结构仍可能出问题。

普通体型的宿主生物接近可用座位时可以自动成为 MC 载具的乘客；宿主本体跟随 MC 座位移动。载具移除、场景暂停或失联时释放桥接持有的移动／AI 控制。不是所有 NPC 类型都已确认支持，也没有为每种 NPC 补齐原生坐姿动画。

## 原生传送与死亡恢复

原生地图传送期间，桥接暂停写入角色位置；传送结束以宿主目的地重新同步 MC。关闭原生菜单后稍等，检查第三人称角色是否恢复。

只剩 UI 或位置不对时：

1. 关闭终末地原生菜单，按 F5 检查是否只是第一人称。
2. 输入 `/endcraft recover`，重新同步并切回第三人称；也可按 Ctrl+Alt+R。
3. 如果原生角色已死亡，先使用原游戏复活或换到存活角色。
4. 仍异常时读取诊断，按 [排错教程](TROUBLESHOOTING.md) 处理。

MC 死亡和持续等待超过 5 秒会尝试自动恢复；恢复并不等同于复活原生已死亡角色，也不会清空你的建筑。
