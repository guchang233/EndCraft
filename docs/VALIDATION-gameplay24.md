# 第 24 版 / 2.0 验证

日期：2026-10-08。真实终末地客户端，Unity 2021.3.34f5 IL2CPP/Vulkan；Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.161.0+26.3、JDK 25。

## 传送与模型

- 用户通过原生地图传送并确认到达目标、传送正常。传送期间宿主位置优先，结束后重新同步 MC 和地形。
- 复现第三人称模式为 1、MC 已捕获模型、宿主却收到零顶点。修复遗漏的 RenAvatar 消息头读取后，宿主记录 864 个顶点；实机截图及用户确认史蒂夫可见。
- 保留死亡前视角、MC 正常重生、`/endcraft recover` 与 Ctrl+Alt+R。此前聊天输入、游戏模式指令和 `/kill @s` 验证见 [第 21 版](VALIDATION-gameplay21.md)。

## MC 伤害与创造模式

- 使用 Minecraft 对命中代理计算的最终伤害，保留武器冷却、暴击、附魔、弓和 TNT 爆炸判定。通过宿主 NewDamage / ApplyModifier 转交实际伤害；按目标最大生命映射 MC 的 20 点生命标尺。
- TNT 实测 MC 伤害约 20.59246，转交原生伤害约 30579.804；对应敌人本地 HP 从 4190.637 降至 0，之后不再列入存活目标。
- 第 24 版后续诊断记录 64 次命中、64 次本地 HP 下降。用户确认 TNT 击杀会增加原生任务计数；实机截图记录挑战进度 11/26。
- 缓存 serverHp 未观察到同步下降，诊断仍如实记录 `confirmed_hp_drops=0`。任务计数已有实机证据，但未验证挑战结算奖励、重登后持久性和所有敌人类型。
- MC 创造模式 invulnerable 标志同步至独立宿主伤害屏蔽句柄，接口报错为空。用户确认受击不掉血；实机战斗时原生 HP 持续为约 3417.456/5304。创造模式不会补满已有损伤。

## 实体与碰撞

- 通过 MC BoatItem.use 成功放置橡木船，用户也放置了白桦木船，并确认船可见。MC 正常船实体、箭、掉落物和粒子经 REN_SCENE 分批纹理消息进入 HGRP 绘制；一帧记录 9414 个实体顶点，渲染错误为空。
- 船可通过正常 MC startRiding 建立乘坐关系。旧实现曾在粗略支撑高度 54.0 与实际地面约 54.82093 之间产生服务器位置纠正。
- 修复平滑船碰撞的地形恢复高度；客户端和服务器共用计算，普通 MC 方块碰撞继续保留。热更新后船实际高度恢复到约 54.82093，向下碰撞返回零，上船采样保持乘坐关系，未再出现该次位置纠正。
- 新增宽船碰撞回归测试，验证高度场替换粗略支撑时的恢复，以及客户端预测结果在集成服务器重放时的一致性。
- 键盘驾驶与 Shift 下船需要真实终末地窗口在前台。桥接在后台发布 menuOpen 并释放虚拟键，因此后台自动输入不能作为物理按键验收证据。完整水上浮力、宿主流体映射和所有载具尚未验收。

## 构建与局限

25 项 Java 测试通过；原生 alpha 裁剪、相机、宿主传送权威及模块 ABI/生命周期检查通过。日志、存档、认证配置、账号截图和实际敌人实例编号留在本机，不提交 GitHub。

高度场不完整表示墙壁、洞穴和多层地形；NPC 寻路、跨新地图建筑持久锚定、输入完全隔离、宿主伤害到 MC 装甲/盾牌同步尚未完成。仅验证当前本机版本；缓存 serverHp、奖励结算和重新登录后的状态需要继续验证。
