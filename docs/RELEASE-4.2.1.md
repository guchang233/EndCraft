# EndCraft 4.2.1

修正旧版按敌人最大生命换算伤害，导致普通敌人与 Boss 的击杀次数接近的问题。宿主模块升级为 `endcraft.gameplay39`。

## 伤害规则

```text
原生伤害输入 = MC 命中伤害 ÷ 5 × 当前终末地角色攻击力 × damage_multiplier
```

不再使用目标最大生命作为伤害倍率。武器伤害和 MC 已计算的暴击继续参与换算，角色攻击力变化影响后续攻击；保留现有 `NewDamage / ApplyModifier` 提交路径。

`damage_multiplier` 默认为 1，可在 EFML 模块配置中调整，范围 0.01 到 100。无效配置被拒绝并保留原倍率；读取不到有效角色攻击力或计算溢出时，不退回旧版百分比算法。详细规则见 [伤害说明](COMBAT.md)。

## 升级

- 导入 `EndCraft-gameplay39-4.2.1-win-x64.zip` 和 `EndCraft-probe-4.2.1-win-x64.zip`，启用两者，停用 gameplay38 等旧玩法模块。
- 继续从官方鹰角启动器启动终末地，使用已验证的 EFML xinput 代理加载方式。
- 伤害修正位于宿主，已有 4.2.0 MC JAR 可继续使用。发行页同时提供版本号一致的 NeoForge 1.21.1 与 Fabric 26.3 JAR；两种客户端的存档不能混用。
- 附带包含固定版本上游代码的源码包及 SHA-256 校验和。第三方模组、个人配置和光影包不随附件分发。

## 诊断与验证

- 新增伤害公式回归，覆盖不同血量目标、武器伤害、MC 暴击、角色攻击力、倍率与异常数值。
- 模块 ABI/配置检查验证默认算法、动态倍率更新，以及无效初始化和更新不会破坏已有状态。
- 16 项 Python 工具检查通过，倍率调整保留世界锚点与启动器配置。
- 本机原生构建通过，gameplay39 已实际加载并接通正式 NeoForge 客户端，附近同步到 5 个敌人；从运行中的游戏确认了 `System.Double get_atk()` 签名。
- **尚未收到真实命中记录，实际扣血、普通敌人与 Boss 的击杀次数及实战平衡未验证。** 本版按用户要求在此范围下发布。

测试工具另外支持定位明确指定、已安装 EndCraft 的正式 NeoForge 实例；重新打开桥接存档时，可复位此前退出世界留下的打开标记。不会重复启动或强制终止已有游戏。

本版保留 4.2.0 的渲染、输入隔离、性能优化和已知限制；完整安装步骤见 [README](../README.md)。
