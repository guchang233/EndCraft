# 第 27 版验证

日期：2026-10-08。宿主版本与 Minecraft/Fabric/JDK 版本同第 24 版。共享内存仍为版本 12，可选标志和事件不改变既有结构布局。

## 爆炸

- 独立空区域加入一个测试木板，用普通 PrimedTnt 爆炸；爆炸后测试木板被破坏，区域内无新增石头/矿石。
- 同一区域前后挖掘标记均为 0，没有写入新的宿主地形挖孔；旧区域仍有原有标记，未清空存档。
- 保留 MC 普通爆炸对命中代理的伤害和已验证的宿主伤害转交路径。此前真实敌人死亡/原生任务计数证据见第 24 版。

## 乘坐

- 第 25 版首次乘坐限制误把碰撞宽约 2.2 的普通敌人排除。调整代理座位尺寸及宿主体型限制后，真实敌人可自动占据船的两个座位，随后船移动约 1.72 方块，代理及宿主本体同步移动。
- 载人矿车也通过普通 startRiding 自动装入一个敌人；测试移动约 3.14 方块后，宿主本体随乘客位置更新。
- 通过独立根句柄保留宿主原对象并暂停其原生 AI、移动等组件。诊断记录五个由桥接暂停的组件，原生乘客位置与 MC→宿主坐标换算一致；不是仅移动不可见代理。
- 测试载具因处在玩家高度场覆盖范围外，使用仅限测试实体的无重力控制来验证乘客位置转交；不能据此声称水上浮力或覆盖范围外地形已经完成。
- 移除测试载具后，MC 乘坐关系取消，宿主 riding 列表为空，自己的组件恢复，接口错误为空。第 27 版记录正常下车释放；菜单/传送会停止乘坐控制，返回后近距离自动装入仍可恢复。
- 验证普通敌人本体；友好 NPC 的根组件接口已接入，但所有友好 NPC 类型以及原生专用坐姿动画未逐一验收。过大体型（宽>=3.5 或高>=4 宿主单位）、演出角色等不参与自动乘坐。

## 玩家下船

- 用真实 MC 船和 ServerPlayer.startRiding/stopRiding 路径验证，正常建立和取消乘坐关系。
- 一次退出位置 Y 约 58.703，同位置测得宿主地面约 58.632；之后正常落地并保持 vehicle=null，没有落在粗略地面下。
- 三项新增回归覆盖小数地面高于粗略体素、已放置方块阻挡一个方向、MC 高平台落点保持。
- 已验证下车计算和服务器实际状态；物理键盘 Shift 操作仍依赖宿主窗口在前台。

## 交付与边界

28 项 Java 测试通过，原生相机、alpha 裁剪、传送权威、ABI/生命周期及事件/渲染环测试通过。认证索引、运行日志、实际对象编号、账号截图和 MC 存档不提交 GitHub。

本轮运行曾记录两次未采样下降保护，之后恢复就绪；这进一步说明当前地形采样范围仍有限。

高度场对墙、洞穴、多层结构、宿主水面和远处载具的覆盖仍有限，NPC 自主寻路并未转换为 MC 路径搜索。普通敌人伤害与原生任务计数已验证；跨重登结算/奖励仍未验证。旧版自动生成的真实 MC 方块不做无来源判定的批量清除。
