# 实现状态索引

当前发行版本为 **4.1.0**（Fabric 26.3 与 NeoForge 1.21.1 两个客户端），宿主模块 `endcraft.gameplay34`，协议版本 12。

本文件保留原实现记录的入口；当前原理与能力说明已整理到 [实现原理](ARCHITECTURE.md)，安装和操作分别见 [安装教程](INSTALL.md) 与 [操作教程](USER-GUIDE.md)。

## 当前验收

| 能力 | 结论与证据 |
|---|---|
| 角色、HUD、建造与场景绘制 | 当前场景已有实机表现；其他构建／设备不保证 |
| 玻璃、染色玻璃与 MC 水 | 用户确认正常；[第 33 版记录](VALIDATION-gameplay33.md) |
| 地形与退出 | 上坡子步跟随、输入保存退出死锁回归通过；多层地形有限 |
| 武器、爆炸伤害与免伤 | 本地 HP、死亡、任务击杀与创造免伤已有实测；[第 24 版](VALIDATION-gameplay24.md) |
| 原生受击动作 | 12 次调用、6 次组件状态变化；[第 31 版](VALIDATION-gameplay31.md) |
| 载具乘客与下车 | 普通体型路径接入，覆盖范围有限；[第 27 版](VALIDATION-gameplay27.md) |
| 坐标锚点 | 初始化前保存旧锚点，启动从当前宿主位置接续；跨新地图语义锚定未完成 |

| TNT 炸原生岩石 | 接口已接入，但仍待原生炸弹样本与实机验收 |
| 光影包 | 尚未兼容 |
