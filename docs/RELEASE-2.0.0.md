# EndCraft v2.0.0

日期：2026-10-08。模块身份 `endcraft.gameplay27`，共享内存协议版本 12，新增兼容的可选 invulnerable、可乘坐/已乘坐标志及乘客事件。1.0 标签与发行附件保持原样。

## 本次变化

- 修复原生地图传送的位置争夺、目的地同步和第三人称史蒂夫模型消失。
- 保留 Minecraft 剑、弓、暴击、冷却及 TNT 爆炸的实际伤害计算，按敌人最大生命增强伤害，转交宿主伤害流程。实机确认敌人掉血、死亡和原生任务击杀进度增加。
- 创造/旁观模式同步宿主免伤，切回生存或关闭桥接时撤销自己的保护。
- 加入船、箭、掉落物及粒子的实体场景网格；修复船在粗略地形高度与实际地面之间的位置纠正。
- 普通宿主生物接近船/载人矿车时自动乘坐，MC 管理座位与乘客位置，宿主本体同步移动；下船、销毁载具、失联或场景暂停会释放自己的 AI/移动控制。
- 关闭遗留的宿主地形方块化，TNT 不再补出石头、矿石坑壁，已放置 MC 方块的爆炸破坏和敌人伤害继续保留。
- 下船落点检查原生高度场和已放置方块，避免落进粗略碰撞地面下。
- 包含 1.0 后续修复：1920×1080 实测 HUD（上限 4K）、20% 菜单遮罩、鞘翅与烟花、游戏模式指令、死亡视角恢复和 `/endcraft recover`。

## 使用

本机已加载修复版并配置下次启动自动运行。F5 切视角；`/gamemode creative` 启用创造及宿主免伤，`/gamemode survival` 回到生存。只剩 UI 时输入 `/endcraft recover`。船需要空旷位置右键放置，右键乘坐、Shift 下船。切回聊天窗口会释放 MC 按键。

伤害映射为「MC 最终伤害 / 20 × 目标最大生命」，例如 7 点对应 35%。创造模式不会补满切换前的损伤。原生菜单和传送期间桥接暂停，以原游戏位置为准。

## 产物和构建

- `EndCraft-gameplay27-2.0.0-win-x64.zip`：宿主模块、清单及许可证。
- `endcraft-guest-2.0.0.jar`：对应 Fabric MC 模组。
- `EndCraft-2.0.0-source.zip`：当前源码与固定提交的两个上游源码。
- `SHA256SUMS.txt`：附件校验。

需要配套 Better-Endfield Host、独立 Minecraft 实例和源码工具链；不是把 JAR 直接放进终末地目录即生效的独立安装器。构建与注册步骤见 README；只启用一个 gameplay 模块，升级时先停用旧桥接，保留已加载的 DLL，使用新身份注册。构建需要 Windows x64、Visual Studio C++、JDK 25、Python 3；固定版本见 THIRD-PARTY-NOTICES。

## 已知限制

这是实机联动原型。复杂地形、多层碰撞、NPC 寻路、原生 NPC 专用坐姿动画及所有友好 NPC 类型的验收、跨地图建筑持久锚定、完整输入隔离和宿主水域到 MC 流体的映射未完成。战斗中本地 HP、死亡和任务计数已验证，缓存 serverHp 未观察到下降，重登持久性与奖励结算未验证。仅确认本机当前游戏版本和图形管线。

完整证据与验收边界见 [第 24 版验证](VALIDATION-gameplay24.md) 及 [第 27 版验证](VALIDATION-gameplay27.md)。发行不包含账号配置、MC 存档、游戏文件、运行日志或含 UID 的截图；保留项目和上游许可声明。

旧版本生成的石头/矿石已成为存档中的 MC 方块，本版不自动清空这些方块。
