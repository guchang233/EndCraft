## 攻击仍待实机敌人验收

普通攻击适配器已加载，无运行错误，附近敌人计数为 0，因此请求数、受理数和实际扣血确认均为 0。

攻击路径：宿主敌方 Entity → MC 隐形命中代理 → 真实 MC 命中事件 → 宿主普通定向攻击。游戏自行决定攻击可否释放及实际伤害。适配器同时读取目标 HP、serverHp；只有两者下降才记录确认。该观测不能单独建立每次伤害的因果关系（队友、持续伤害也可能扣血），最终验收需控制其他伤害来源。

尚未验证近战实际扣血；未实现弓/TNT/附魔的独立伤害对应、敌人攻击到 MC 的回传。MC 武器伤害数值目前不等于宿主伤害。不能把适配器已安装写成战斗兼容完成。

## 复验步骤

1. 当前游戏无需重启；已加载第 18 版。E 打开库存，将鞘翅穿在胸甲栏，将烟花放在快捷栏。
2. 从安全高处跳出，空中再按空格展开，选择烟花右键推进；检查移动、建筑遮挡与落地。受控测试成功不替代此输入和起降检查。
3. 到敌人附近，使用 MC 剑左键命中，读取 `combat.requests` / `accepted` / `confirmed_hp_drops` 和实际敌人血量。附近无人时不能完成验收。
4. 下次启动自动使用第 18 版；这一启动配置尚未通过重启实测。

复杂立体地形、高速飞行时碰撞预取、NPC 碰撞/寻路、跨场景建筑定位、完整输入隔离仍有限制。
